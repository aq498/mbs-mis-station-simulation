# MBS-MIS Station Flow Simulation

Python model simulating 24-hour passenger dynamics, bike-sharing fleet redistribution, and train dwell times for MBS-MIS transit station.

# Key Features
* **Dynamic Passenger Profiling:** Models morning (08:00) and evening (18:00) peak demand flows.
* **Fleet Management Algorithm:** Simulates predictive redistribution of shared bikes based on live inventory thresholds.
* **Dwell Time Impact Analysis:** Evaluates operational impact of passenger boarding/alighting and off-peak bike loading.

# Quick Start
```bash
pip install -r requirements.txt
python simulation.py
